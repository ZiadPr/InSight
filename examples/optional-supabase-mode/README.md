# تنبيه مهم: وضع Supabase الاختياري المؤرشف (غير مكافئ أمنياً)

> **تحذير معماري وأمني (ADR-001):**
> هذا المجلد نُقل من المسار الرئيسي إلى `examples/optional-supabase-mode/` وهو **مؤرشف كمرجع تصميمي لـ PostgreSQL / RLS / Edge Functions فقط**.
> الواجهة الأمامية الحالية لم تعد تتصل بـ Supabase، وتعتمد حصرياً على الخادم الرسمي `server.ts`.

## الفجوات الأمنية والوظيفية مقارنة بالخادم الرسمي (`server.ts`)

| الميزة / الضابط الأمني | الخادم الرسمي (`server.ts`) | هذا الأرشيف (`examples/optional-supabase-mode/`) |
| :--- | :---: | :---: |
| **التشفير التطبيقي E2EE (ECDH P-256 + ECDSA + AES-256-GCM)** | ✅ مفعل وإلزامي للعمليات الحساسة | ❌ غير مطبّق (يعتمد على HTTPS/TLS فقط) |
| **بوابة Admin Step-Up + إغلاق تلقائي للخمول** | ✅ مطبّق بالكامل | ⚠️ جداول الترحيل موجودة بدون ربط بالواجهة |
| **جدار الحماية WAF / SQLi / HPP / Method-Override** | ✅ مطبّق على مستوى Middleware | ❌ غير مكتمل في Edge Functions |
| **تكامل Cloudflare WAF + Turnstile من لوحة التحكم** | ✅ مدمج بالكامل | ❌ غير مدعوم |
| **تعدد شاشات الاستقبال وجدولة إخفاء QR** | ✅ مدعوم في API والواجهة | ⚠️ دوال SQL مبدئية فقط غير مربوطة بالواجهة |
| **توحيد المسميات (Employee vs Student)** | ✅ موحّد لموظفي المؤسسة | ⚠️ يحتوي بقايا مسميات `student_id` / `campus_settings` |

لا يُنصح بنشر هذا الوضع في بيئة إنتاجية دون استكمال مواءمة المخطط وإضافة طبقة التشفير والمصادقة الموازية للخادم الرسمي. راجع [`docs/DECISIONS.md`](../../docs/DECISIONS.md) و[`docs/SECURITY.md`](../../docs/SECURITY.md).
